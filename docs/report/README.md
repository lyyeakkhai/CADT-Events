# Project submission reports

Draft templates for academic / course submission reports for **CADT Events**. Fill each file section-by-section; they already link to living docs under `docs/`.

| File | Topic |
|---|---|
| [`1-HCI-report.md`](./1-HCI-report.md) | Human–Computer Interaction |
| [`2-Database-report.md`](./2-Database-report.md) | Database design & administration |
| [`4-SE-report.md`](./4-SE-report.md) | Software Engineering process & design |
| [`5-backend-report.md`](./5-backend-report.md) | Backend / API |
| [`6-Final-repentation-slide.md`](./6-Final-repentation-slide.md) | Final presentation slide outline |

## How to use

1. Pick one report file.
2. Replace `_placeholders_` and empty tables.
3. Pull facts from `docs/product/`, `docs/architecture/`, and the code.
4. Add screenshots, ERDs, and test evidence in appendices.
5. Export to PDF / slides if the course requires it.

## Note on numbering

Report numbers follow the course list you provided (`1`, `2`, `4`, `5`, `6`). Add `3-…` later if needed.
