# Product

What we're building and why. Lives upstream of architecture — answers "what problem are we solving?" before "how do we build it?".

## Documents

| Doc | Purpose |
|---|---|
| [prd.md](./prd.md) | Product Requirements Document — vision, personas, scope, success criteria |
| [implementation-plan.md](./implementation-plan.md) | Phased delivery plan with milestones and links to architecture docs |

## What goes here

- **PRDs** — one per major release/version (PRD V1, PRD V2, …)
- **Personas** — detailed user research, separate from the PRD if it grows
- **Roadmap** — quarterly milestones, release planning
- **Success metrics** — KPIs, OKRs, measurement plans
- **Implementation plans** — tactical delivery breakdowns

## What does NOT go here

- API contracts → `../api/`
- System design → `../architecture/`
- Per-feature technical specs → `../features/`
